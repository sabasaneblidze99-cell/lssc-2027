# Mondo Arizona Prime (v2) - solo Los Santos

Dati estratti da `recovery/tools/arizona/extract.py` dall'archivio "Arizona Prime(v2)" fornito dal proprietario del server.
Solo dati del mondo (coordinate, interni, modelli, prezzi): **nessun codice dei sistemi** e **nessun dato personale**
(proprietari azzerati, nessun account/password/email/IP).

Filtro: Los Santos (x 44.6..2997, y -2892.9..-768). Gli interni personalizzati che stanno fuori zona si tengono
se sono l'interno di un edificio di Los Santos (oggetti entro 120 m dall'uscita di una casa, business o porta).

| File | Contenuto |
|---|---|
| houses.json | case: ingresso, punto interno, interno GTA, prezzo, livello, classe, garage |
| businesses.json | business: nome (russo), ingresso, punto interno, interno GTA, prezzo |
| teleports.json | porte degli edifici pubblici (ospedale, municipio, polizia, gang, ...) |
| vehicles.json | veicoli di fazione, di lavoro, motorini a noleggio |
| parked_vehicles.json | auto personali del server di origine, importate senza proprietario |
| mapping.json | oggetti di mapping con materiali e testi |
| removed_buildings.json | edifici GTA rimossi dal mapping |
| gangzones.json | zone delle gang (non ancora usate) |
