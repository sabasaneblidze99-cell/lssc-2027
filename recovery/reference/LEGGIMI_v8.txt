1) DATABASE - scegli UNA strada
-------------------------------
A) INSTALLAZIONE NUOVA (si riparte da zero, i vecchi account spariscono):
   - in phpMyAdmin cancella (o rinomina) il vecchio database "lsrp";
   - dalla pagina iniziale (NON dentro un database): Importa -> 1_DATABASE\A_installazione_nuova\installa_database.sql -> Esegui.
B) AGGIORNAMENTO (tieni account e personaggi della v6/v7):
   - in phpMyAdmin clicca il database "lsrp" a sinistra, poi Importa -> 1_DATABASE\B_aggiornamento_da_v6_v7\aggiorna_012.sql -> Esegui.
   - Va importato UNA volta sola (la seconda darebbe "Duplicate column": innocuo, ma non serve).

2) SERVER
---------
Nella cartella del tuo server open.mp:
- copia 2_SERVER\gamemodes\lsrp.amx (sostituisci);
- se e' un server NUOVO: copia anche config.json, mysql.ini e le cartelle (leggi i .txt in components e plugins).
All'avvio nel log devono comparire:
   [DB] connesso
   Successfully loaded component CEF
   [DISTRICT] boot living completato: 3 quartieri
Senza cef.dll usa lsrp_senza_cef.amx (rinominalo lsrp.amx).
